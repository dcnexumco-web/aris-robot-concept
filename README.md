A conceptual robotics website designed and developed using HTML and CSS.

The project presents ARIS (Autonomous Residential Intelligence System), a fictional residential robot concept through a structured engineering-style web interface.

This project was created primarily to demonstrate my HTML and CSS skills, including layout design, responsive design, CSS Grid, Flexbox, positioning, pseudo-elements, and custom visual elements built entirely with CSS.

---

## Preview

The website presents the ARIS concept through several sections:

- Project introduction
- Robot concept
- System concept
- Engineering components
- Development stages
- Technical-style visual presentation

---

## Technologies Used

- HTML5
- CSS3

No JavaScript, frameworks, or external UI libraries were used.

This project helped me practice:

- Sections and articles

## CSS Concepts Used

The design uses several CSS techniques, including:

- CSS Grid
- Flexbox
- Responsive design
- Media queries
- Relative and absolute positioning
- CSS pseudo-elements
- Borders and border-radius
- Box shadows
- CSS gradients
- Background patterns
- Typography
- Spacing and alignment
- Hover effects
- `clamp()` for responsive typography

The robot illustration on the homepage was created using HTML elements and CSS rather than an image.

---

## Design

The visual style was designed around an engineering and technical aesthetic.

The interface uses:

- Structured layouts
- Grid patterns
- Technical labels
- Numbered sections
- Dark and light contrast
- Orange accent elements
- Minimal typography

The goal was to make the website feel like a presentation of a robotics concept rather than a conventional business landing page.
